## 🚀 Setup Instructions

### 1. Get Gemini API Key (Optional but Recommended)

1. Go to [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Sign in with your Google account
3. Click "Create API Key"
4. Copy the API key

### 2. Add to Environment Variables

Add this line to `/server/api/.env`:

```bash
GEMINI_API_KEY=your_api_key_here
```

**Note:** The system works without Gemini API key! It will use statistical fallback methods for forecasting and insights.

### 3. Restart the API Server

```bash
cd /Users/shahriar/Desktop/github/growth-monitor
./run-all-servers.sh
```

Or if running separately:

```bash
cd server/api
npm run dev
```

## 📊 API Endpoints

All endpoints are available at `/api/analytics/*`:

### Core Analytics
- `GET /api/analytics/overview` - Comprehensive dashboard metrics
- `GET /api/analytics/sales-trend?includeForecast=true&groupBy=day` - Sales trends with forecasting
- `GET /api/analytics/customer-insights` - Customer behavior and CLV analysis
- `GET /api/analytics/campaign-analytics` - Campaign performance metrics
- `GET /api/analytics/ai-insights` - AI-powered business insights

### Cache Management
- `DELETE /api/analytics/cache` - Clear analytics cache (refreshes data)

## 🔧 Customization

### Adjust Forecast Period

In the frontend, modify the API call:

```javascript
// Change from 30 days to 60 days
const result = await apiFetch("/analytics/sales-trend?includeForecast=true&groupBy=day&forecastPeriod=60");
```

### Modify Grouping

```javascript
// Group by week instead of day
const result = await apiFetch("/analytics/sales-trend?includeForecast=true&groupBy=week");
```

### Cache Duration

In `analytics-enhanced.controller.js`, change cache TTL:

```javascript
// Change from 5 minutes (300s) to 10 minutes (600s)
await redis.set(cacheKey, JSON.stringify(overview), 'EX', 600);
```

## 🎯 Data Requirements

For best results, ensure you have:

- **Sales data** with dates, amounts, channels, regions, products

## 🚨 Troubleshooting

### No data showing
- Check if sales/customers/campaigns exist in database
- Verify user is assigned to a company
- Clear cache with the refresh button

### Gemini API errors
- Verify API key is correct in .env
- Check API quota/billing in Google Cloud Console
- System will fall back to statistical methods if Gemini fails

### Slow loading
- Analytics are cached for 5 minutes
- First load may be slower
- Consider increasing cache duration

## 📈 Performance Tips

1. **Cache Management**: Analytics are cached for 5 minutes. Use refresh button only when needed.
2. **Date Ranges**: Shorter date ranges load faster. Default is 30-90 days.
3. **Pagination**: Top customers/campaigns are limited to 5-10 items for performance.
4. **Background Loading**: Each tab loads data only when first accessed.
